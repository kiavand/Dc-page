# پیگیری حضوری؛ ثبت‌نام و تیم‌سازی
دیدار حضوری :: پیگیری واقعی با یک دیدار حضوری شروع می‌شود. یک قهوه، یک گفتگوی صمیمی، و فرصتی برای شنیدن حرف‌های طرف مقابل.
گوش دادن :: اول بپرس و با دقت گوش بده. هدف‌ها و نگرانی‌های او را بشناس. ثبت‌نام زمانی اتفاق می‌افتد که فرد احساس کند دیده شده است.
مسیر ثبت‌نام :: بعد از گفتگو، قدم بعدی را ساده و روشن توضیح بده. اگر آماده بود، ثبت‌نام را همان‌جا و کنار هم انجام بده. اگر نه، یک زمان مشخص برای دیدار بعدی بگذار.
تیم‌سازی :: ثبت‌نام پایان کار نیست، شروع تیم‌سازی است. همان روز اولین قدم‌ها را با او بنویس و زمان جلسه‌ی بعدی را هماهنگ کن.
ادامه رابطه :: بعد از ثبت‌نام، او را رها نکن. یک پیام کوتاه، یک تماس یا یک دیدار دوباره، نشان می‌دهد که تنها نیست.
جمع‌بندی :: پیگیری حضوری یعنی اعتماد، گوش دادن و همراهی. اگر تیمی می‌خواهی که بماند، رابطه را از امروز بساز.
