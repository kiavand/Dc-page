# پشتکار | انیشتین
پشتکار :: انیشتین هم از اول نابغه نبود!
انیشتین :: فکر می‌کنی انیشتین از همون بچگی نابغه‌ای بود که همه تحسینش می‌کردن؟
واقعیت :: مسیرش اون‌قدرها هم ساده نبود.
چالش :: او در دوران تحصیل، مثل خیلی از آدم‌های دیگه با چالش‌هایی روبه‌رو می‌شد؛ اما یه ویژگی متفاوت داشت: هیچ‌وقت از یاد گرفتن دست نمی‌کشید.
سوال :: همیشه سؤال می‌پرسید، کنجکاوی می‌کرد و دنبال جواب‌هایی بود که شاید هیچ‌کس بهشون فکر نکرده بود.
روحیه :: همین روحیه باعث شد بعدها نظریه‌هایی ارائه بده که نگاه دنیا به علم رو تغییر داد.
درس :: حالا می‌دونی چه درسی می‌تونیم از زندگی انیشتین بگیریم؟
موفقیت :: اینکه برای موفق شدن، لازم نیست از همون روز اول بهترین باشی.
اعتماد :: لازم نیست همه بهت ایمان داشته باشن یا همیشه جواب درست رو بدونی.
یادآوری :: یادت باشه؛ آدم‌های بزرگ لزوماً از اول متفاوت نیستن، گاهی فقط بیشتر از بقیه برای رشد کردن تلاش می‌کنن.
